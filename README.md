# TapeDeck Models

On-demand stem-separation models for TapeDeck. Assets live in [Releases](https://github.com/StancuRobertAlexandru/TapeDeck-Models/releases); TapeDeck downloads them through SonicSwift and verifies each file by SHA-256.

Current: `models-v1` — 4-stem HTDemucs (vocals, drums, bass, other), Core AI (OS 27) and Core ML (OS 26), FP16.

Models are converted from [Demucs](https://github.com/facebookresearch/demucs) by Meta Platforms, Inc. (MIT).
